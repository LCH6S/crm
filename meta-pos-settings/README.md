## 2026-11-16 电子发票入口与门店业务控制

POS 设置 > 应用功能 > H5 应用设置增加电子发票入口开关，只控制显隐。门店是否可用由门店开票设置中的手动开票开关及可开票状态判定；未开通时进入提示功能未开通。品牌统一项目和门店单独项目不合并，配置门店项目后只使用门店项目。此处仅同源浏览器模拟，无生产配置API。联动评审：https://lch6s.github.io/meta-posm-workstation/einvoice/review.html 。
