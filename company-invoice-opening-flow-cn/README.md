# 中国大陆公司发票功能开通流程图

本流程图基于 [公司开通发票功能 PRD V0.2](../../docs/leqi-joint-opening/company-invoice-opening-prd.md) 整理，只覆盖中国大陆公司。

- [company-invoice-opening-flow-cn.png](./company-invoice-opening-flow-cn.png)：位图预览。
- [company-invoice-opening-flow-cn.dot](./company-invoice-opening-flow-cn.dot)：Graphviz 可编辑源文件。

## 边界

- 不包含马来西亚及其他海外公司开通。
- 支付主体、收钱吧商户和渠道商户号只作乐企联用的只读前置，不在本流程创建。
- RPA 运营内部状态不在销售端展示。
- 腾讯渠道子状态失败时，公司申请和乐企联用模式仍保持开通中。
